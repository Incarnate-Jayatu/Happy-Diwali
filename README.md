## 🌟 About the Project

**Happy Diwali** is a beautifully designed, interactive digital greeting created to celebrate the spirit of Diwali and share heartfelt wishes with friends, family and loved ones.

Instead of a conventional greeting card, this project presents an immersive festive experience. Visitors are welcomed with an animated envelope that reveals a personalized Diwali message when opened.

Designed with traditional Indian festive aesthetics, elegant animations and warm golden tones, the website brings together technology and the timeless joy of celebrating Diwali.

**A special Diwali greeting from the Bhattad Family.**

## ✨ Features

- **Interactive Greeting Envelope:** An animated envelope that opens to reveal the Diwali wishes.
- **Festive Animations:** Beautiful visual effects, glowing elements and floating animations.
- **Fireworks & Sparkles:** A festive animated background that enhances the celebration.
- **Traditional Diwali Greetings:** Heartfelt wishes presented in English, Hindi and Sanskrit.
- **Animated Diyas:** Decorative traditional elements that bring the festive atmosphere to life.
- **Family Illustration:** Animated family characters that add a personal touch to the greeting.
- **Background Sound:** An interactive sound toggle for the festive experience.
- **Elegant Festive Design:** A combination of deep purple, traditional red, warm gold and cream.
- **Responsive Experience:** Designed to work across desktop and mobile screens.
- **Personalized Message:** A special greeting from Avinash Bhattad, Sapana Bhattad, Jayatu Bhattad and Raghav Bhattad.

## 🎨 Design & Experience

The website draws inspiration from traditional Indian Diwali celebrations.

| Element | Design Inspiration |
|---|---|
| Deep Purple Background | Night sky during Diwali |
| Golden Accents | Light, prosperity and celebration |
| Red Envelope | Traditional festive greetings |
| Diyas | Symbol of hope and positivity |
| Sanskrit Shlokas | Indian cultural heritage |
| Animated Effects | The joy and excitement of Diwali |

## 🛠️ Technologies Used

- **HTML5** – Website structure and content.
- **CSS3** – Styling, animations, transitions and responsive layouts.
- **JavaScript** – Interactive elements and dynamic visual effects.
- **HTML Canvas** – Animated festive background effects.
- **Google Fonts** – Devanagari typography using Noto Serif Devanagari.
- **Vercel** – Website deployment and hosting.

## 💻 Run Locally

Want to experience or explore the project locally?

1. Clone the repository:

   ```bash
   git clone https://github.com/Incarnate-Jayatu/Happy-Diwali.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Happy-Diwali
   ```

3. Open `index.html` in your preferred web browser.

No additional dependencies or build tools are required.
